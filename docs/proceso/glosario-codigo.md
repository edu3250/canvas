# Glosario de código

Correspondencia fija entre los términos del [diseño](../diseno-inicial.md) y los nombres en el código. Quien introduce un término de dominio nuevo, al definir o al construir un hito, añade su fila en el mismo PR. Una propuesta de arquitectura no adoptada no añade filas.

| Término | Código |
| --- | --- |
| Espacio | `Space` |
| Lienzo | `Canvas` |
| Inicio | `Home` |
| Panel | `Panel` |
| Acceso directo | `Shortcut` |
| Ventana activa | `ActiveWindow` |
| Vista (posición y zoom) | `View` |
| Vista de retorno | `ReturnView` |
| Acomodo | `Layout` |
| Carpeta del espacio | `SpaceFolder` |
| Acomodo de Inicio (posiciones de sus iconos) | `HomeLayout` |
| Minimapa | `Minimap` |
| Registro de devolución | `WindowRecovery` |
| Instancia de ventana | `WindowInstance` |
| Marco del lienzo | `CanvasFrame` |
| Luz del espacio (color que marca el panel activo) | `SpaceLight` |
| Valores del sistema visual Mesa de luz | `VisualTokens` |
| Orilla | `EdgeBar` |
